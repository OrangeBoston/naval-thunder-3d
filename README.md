# 怒海争锋 Naval Thunder 🌊⚓

一个《战舰世界》风格的网页 3D 海战游戏 Demo。默认 **8v8**，可自定义双方舰队数量（1~8），并可在开始界面从三种战舰中选择座舰：战列舰「北岭号」、巡洋舰「苍岚号」（带鱼雷）或驱逐舰「疾风号」。

![技术栈](https://img.shields.io/badge/Three.js-r128-blue) ![零依赖](https://img.shields.io/badge/依赖-零-green) ![离线可玩](https://img.shields.io/badge/离线-可玩-orange)

## 🚀 快速开始

**方式一（最简单）**：直接双击 `index.html`，在浏览器中游玩。

**方式二（本地服务器）**：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
# 浏览器打开 http://127.0.0.1:8787/
```

推荐使用 Chrome / Edge。所有资源（包括 Three.js）均为本地文件，完全离线可玩。

| 按键 | 功能 |
| --- | --- |

| 速度 1× / 6× | 游戏速度切换（默认 1×，可切 6× 快进），快捷键 `T`；亦可在战斗中左上角、开始界面与暂停菜单点击，设置自动保存 |
| 左键 / `空格` | 主炮齐射（按住自动连射） |
| 滚轮 | 三级瞄准镜变焦（55° / 30° / 14°）；鱼雷模式下调整散布角 |

| `Shift` | 按住进入狙击镜 |
| `3` | 鱼雷瞄准模式：鼠标控向、滚轮调散布、左键发射（再按 3 退出） |
| `1` / `2` | 切换 AP 穿甲 / HE 高爆弹 |

## ⚔️ 核心玩法

- **编队自定义**：开始界面用「−／＋」调整己方与敌方舰队数量（1~8），舰种按驱逐/巡洋/战列混合编成。
- **隐蔽机制**：每舰有被探测距离（BB 4.2km / CA 3.3km / DD 2.6km），敌舰靠近才会被点亮——未点亮的敌舰模型、标签、小地图全部隐藏。**开火会暴露**（BB 开火后 5.6km 内可见 15 秒），打完记得脱离。AI 同样受隐蔽规则约束（无透视）。
- **弹种切换**（`1`/`2`）：AP 穿甲弹可击穿核心区（2.2~2.4 倍伤害）；HE 高爆弹稳定半伤、32% 起火率。
- **进水**：鱼雷命中 50% 概率进水，持续掉血（维修小组可止住）。
- **弹道物理**：炮弹受重力下坠，飞行 2~10 秒。鼠标上下调节瞄准距离（准星=弹着点，水面金色圆环标记落点）；准星靠近已点亮敌舰时**辅助瞄准自动预判提前量**（标记变亮金色）。
- **三种舰种**：战列舰（重炮厚甲）、巡洋舰（速射平衡）、驱逐舰（灵活 + 鱼雷）。
- **核心区机制**：命中核心区造成 2.2~2.4 倍伤害，会看到金色的「核心区」伤害数字。
- **鱼雷**：敌我驱逐舰都会在侧舷对齐时发射鱼雷，注意「⚠ 鱼雷来袭」告警和小地图上的红色信号点。
- **起火**：被大口径炮弹命中可能起火，持续掉血。
- **AI**：敌方会绕行保持距离、之字机动规避、岛屿掩护、集火优先目标；友军 AI 也会自主作战。

## 🗂️ 代码结构

```
index.html        HUD 界面 / 开始与结算界面
serve.ps1         零依赖本地静态服务器（可选）
js/
  three.min.js    Three.js r128（本地化）
  audio.js        WebAudio 程序化音效（炮击/爆炸/海浪/主机，无音频文件）
  effects.js      GPU 粒子系统：炮口焰、爆炸、水柱、尾流、烟柱、水面冲击环
  ships.js        舰种数据、程序化舰体建模、航行物理、弹道解算、炮弹/鱼雷、AI
  main.js         场景/自定义海面着色器/天空穹顶/相机/输入/HUD/小地图/主循环
```

## 🔧 调参与扩展

- 舰船属性（血量、航速、装填、伤害、散布、射程）集中在 `js/ships.js` 顶部的 `SHIP_TYPES`。
- 新增舰种：在 `SHIP_TYPES` 加配置，并在 `buildShipModel` 中为它布置上层建筑与炮塔位。
- 海浪形态：`js/main.js` 中的 `waveHeight`（JS）与 `WAVE_GLSL`（着色器）需保持一致。
- 岛屿布局：`buildIslands()` 中的 `defs` 数组。
